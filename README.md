### Featured Projects

- **[gopher-links](https://github.com/daviwaldow/gopher-links)**: URL shortener written in plain Go (no web frameworks) with a visual dashboard. Creating a link responds immediately, while a background **worker pool** checks whether each destination URL is up, using channels and per-job `context` timeouts. Storage sits behind an interface, and the backend is deployed on Render with the frontend on Firebase Hosting.
